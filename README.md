📊 Python Data Analytics Project: Universities in Morocco
Explore and analyze Moroccan university data with this powerful project! It combines data collection, cleaning, advanced visualizations, and an interactive Tkinter-based interface packed with features, including a dynamic map for geographic insights.

🧹 Data Collection & Cleaning
🗂️ Collect raw data about Moroccan universities.

🤔 Data Analysis
📉 Conduct in-depth trend and statistical analysis.
🔍 Extract meaningful insights from datasets.
🖥️ Interactive Interface (Tkinter)
A feature-rich and user-friendly GUI with:

📥 Import CSV Files: Load datasets directly into the app.
📊 Data Visualization: Display interactive plots within the interface.
🔄 Dynamic Filters: Filter, sort, and process datasets in real time.
🔢 Data Summary: View key statistics like mean, median, and more.
🗺️ Interactive Maps: Explore university locations with zoomable maps.
💾 Export Data: Save modified or filtered datasets to CSV.
📋 Custom Reports: Generate comprehensive reports with visuals.
📦 Libraries Used

Here are the Python libraries powering this project:

tkinter: Build the main graphical interface.
tkinter.ttk: Add advanced widgets like tables and dropdowns.
filedialog & messagebox: Handle file imports and user notifications.
customtkinter: Modernize the GUI for a sleek look.
pandas: Manage and manipulate datasets efficiently.
numpy: Perform numerical operations.
matplotlib: Create and integrate plots within the interface.
matplotlib.backends.backend_tkagg: Embed Matplotlib plots into Tkinter.
tkintermapview: Add interactive maps to visualize geographic data.
